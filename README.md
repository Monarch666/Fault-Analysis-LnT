# Fault Analysis LnT — Industrial Machine Predictive Maintenance

Predictive maintenance, vibration anomaly detection, and machinery failure diagnostic algorithms developed for industrial L&T telemetry datasets.

Developed by **Aadarsh Sinha** ([@Monarch666](https://github.com/Monarch666)).

---

## 🏭 Overview & Methodology

- **Time-Domain & Frequency-Domain Feature Extraction**: RMS, kurtosis, crest factor, skewness, and Fast Fourier Transform (FFT) harmonics for bearing and motor fault isolation.
- **Supervised Classification Models**: Random Forests, XGBoost, and Support Vector Machines trained to classify healthy vs. degraded mechanical states.
- **Predictive Health Index**: Remaining Useful Life (RUL) estimation and degradation trend modeling.
